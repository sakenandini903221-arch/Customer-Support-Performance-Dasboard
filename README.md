# Customer Support Performance Dashboard - Power BI

## Project Overview
This Power BI dashboard analyzes customer support performance and provides insights into ticket resolution, response times, customer satisfaction, and agent productivity.

## Tools Used
- Power BI
- Excel
- DAX

## Key Metrics
- Total Tickets
- Resolved Tickets
- Average Response Time
- Average Resolution Time
- Customer Satisfaction Score (CSAT)
- Agent Performance

## Features
- Interactive Dashboard
- KPI Monitoring
- Ticket Trend Analysis
- Agent Performance Tracking
- Customer Satisfaction Insights

## Business Insights
- Identifies top-performing support agents
- Tracks ticket resolution efficiency
- Monitors customer satisfaction trends
- Helps improve customer support operations
